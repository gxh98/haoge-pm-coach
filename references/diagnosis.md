# 六维能力与卡点判定（diagnosis）

> 何时读我：定位卡点、给雷达打分、判断这轮练哪一维时。

## 一、六维定义与行为锚点

每维 0-100 分。打分只依据"他这轮的实际表现"，不依据他的自我评价。

### 1 用户洞察

| 分 | 行为锚点 |
|---|---|
| 0-40 | 把用户说的需求当结论抄下来 |
| 60 | 能说出用户"说了什么"，说不出"没说什么" |
| 80 | 能从原话里指出未说出口的顾虑，并说出这个顾虑来自哪句话 |
| 95 | 能预测用户下一步动作，且事后对得上 |

### 2 问题定义

| 分 | 行为锚点 |
|---|---|
| 0-40 | 问题是大词（"获客难""没流量"） |
| 60 | 能说出问题发生在哪个环节，但环节是猜的 |
| 80 | 能把问题断在一个可观察的具体动作上，并说明"不解决会损失什么" |
| 95 | 能给出可被推翻的问题陈述（说出什么证据会证明问题定义错了） |

### 3 方案取舍

| 分 | 行为锚点 |
|---|---|
| 0-40 | 方案是功能罗列，越多越好 |
| 60 | 能排序，但不敢删 |
| 80 | 能明确说出这版砍掉什么、为什么敢砍 |
| 95 | 砍完还留了一条后手（什么条件下把砍掉的加回来） |

### 4 优先级

| 分 | 行为锚点 |
|---|---|
| 0-40 | 理由是多因素综合（"都重要"） |
| 60 | 能排序，理由是"更容易"或"更喜欢" |
| 80 | 能用一句话说清为什么先做这个，且这个理由与目标直接挂钩 |
| 95 | 能说出"先做这个会牺牲什么"，并接受这个牺牲 |

### 5 度量

| 分 | 行为锚点 |
|---|---|
| 0-40 | 指标是"效果好不好""口碑" |
| 60 | 能说出指标名，说不出阈值和周期 |
| 80 | 指标名 + 阈值 + 观察周期三件齐全 |
| 95 | 还能说出"这个数字被什么污染"（怎么防止自欺） |

### 6 推动与决策

| 分 | 行为锚点 |
|---|---|
| 0-40 | 面对"再看看"只能说"好的您考虑下" |
| 60 | 会追问，但追问完没有下一步动作 |
| 80 | 能说出一句话把对方推到具体动作上（约时间、给材料、定小承诺） |
| 95 | 能识别对方在拖还是在拒，两种用不同打法 |

## 二、卡点六层判定表

定位时只能选一层，选最靠前的（越靠前越是根因）。

| 层 | 判定证据（出现即判） |
|---|---|
| 看不见用户 | 全程用"他觉得""老板应该"这类推断，没有引用任何用户原话 |
| 定义错问题 | 问题陈述里含大词（获客/流量/转化/体验），且无法指出断在哪一步动作 |
| 不会取舍 | 方案里所有项都保留，或砍的理由是"这个也重要" |
| 不会度量 | 说得出指标说不出阈值，或阈值是"提升明显" |
| 不敢决策 | 反复要更多信息，或把决策推给老板/市场 |
| 不会推动 | 结尾没有具体动作、时间、责任人 |

## 三、雷达更新规则

- 每次训练只动一维，±5 到 ±15 分
- 单次表现好不给满分：95 分要求"预测事后对得上"，不是当场说得漂亮
- 连续 3 次同层卡点 → 在 radar 里标记 `stuck: true`，下一轮必须换一种练法
- 分数只升不因一次失误暴跌：单次失误最多 -10

## 四、80 分的达成判定（不靠教练说）

六维均 ≥ 75，且同时满足：
1. 判断日志 ≥ 20 条，命中率 ≥ 65%
2. 至少一次"盲测案例与真实结局吻合"
3. 至少一次"外部人复述挑漏洞"通过

缺任何一条，都不算 80 分。
