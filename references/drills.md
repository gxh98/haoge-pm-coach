# 微训练库（drills）

> 何时读我：Step 6 给微训练时。一次只给一个，5-30 分钟，必须有可检验产出。

## 看不见用户（洞察）

1. **抄情绪**：翻最近 5 条老板微信，只抄情绪词不抄内容，抄完写一句"他真正怕的是＿＿"。产出：一句话。
2. **只问过去**：给一个老板发一条只问过去的问题（"上次客户最后没在你这儿做，是因为什么？"），把原话记下来。产出：一句原话。
3. **改写处境**：把一条拒绝理由（"太贵了"）改写成"他当时处在什么处境"。产出：三行处境描述。
4. **预测动作**：写下"这个老板下周最可能做的一件事"，下周对账。产出：一条预测 + 对账结果。

## 定义错问题

1. **拆断点**：把"获客难"拆成三个断点句（不知道你／不信你／不着急），选一个。产出：一句话 + 选择理由。
2. **损失量化**：写"这个问题不解决，他下个月损失多少"，给数字或区间。产出：一个数。
3. **句式替换**：把"他需要 X"改写成"他在＿＿情况下会主动找 X"。产出：一句改写。
4. **证伪句**：写"如果＿＿发生，说明我的问题定义错了"。产出：一句可被推翻的陈述。

## 不会取舍

1. **强删**：现有方案列 8 项，强制删到 3 项，每项写"删了会怎样"。产出：3 项 + 5 条删除理由。
2. **砍预算**：预算砍到十分之一，重写一版方案。产出：一页。
3. **放弃句**：写一句"这版我放弃了＿＿，因为＿＿"。产出：一句话。
4. **后手**：写"什么条件下把砍掉的加回来"。产出：一条触发条件。

## 不会度量

1. **补三件**：给一个指标补齐"指标名＋阈值＋观察周期"。产出：一行。
2. **认错线**：写"哪个数字变了，我就承认自己错了"。产出：一个数字 + 阈值。
3. **污染源**：写出这个数字会被什么污染（季节性、口径、刷量）。产出：两条。
4. **给老板看的那一页**：设计"三个月后拿什么给他看，他会说值"。产出：一页纸结构。

## 不敢决策

1. **等信息清单**：列出"我在等的信息"，标出哪些根本拿不到。产出：一张表。
2. **最坏结果**：写最坏结果 + 我赔不赔得起。产出：两行。
3. **截止线**：设一个决策截止时间，写下到点必须做的动作。产出：日期 + 动作。
4. **反向假设**：假设这事已经失败，倒推最可能的三个死因。产出：三条。

## 不会推动

1. **改一句话**：把"好的您考虑下"改写成一句带动作的话。产出：一句原话。
2. **写下一步动作**：写出对方听完后下一步会做的具体动作；写不出就重写那句话。产出：一个动作。
3. **最小承诺**：设计一个不要合同的小承诺（先给一家店免费出 3 条选题）。产出：一句提议。
4. **辨拖与拒**：写下"他是在拖还是在拒"的两条判断依据。产出：两条依据。

## 使用纪律

- 一次一个，不打包
- 做完必须交产出物；没产出等于没练
- 连续两次同一 drill 无效（他说没用）→ 换 drill 或换维度，并记入日志
