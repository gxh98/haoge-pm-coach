# 一手材料清单与取用规则（materials）

> 何时读我：每次出题选材料前。

## 一、允许的材料（按优先级）

| 级 | 材料 | 位置/来源 | 适合练哪维 |
|---|---|---|---|
| P0 | 昊哥与奔驰专修老板的微信原文（尤其"再看看""太贵了""我问问别人"） | 昊哥手机，他贴给我 | 洞察、推动 |
| P0 | 客户付费/拒绝的真实理由 | 同上 | 洞察、定义 |
| P1 | 门店档案原文 | `05-市场资产/首批10家_档案_*.md` | 定义、优先级 |
| P1 | 一手信息档案原文（录音/直播原文） | `02-一手信息档案/*.md` | 洞察、取舍 |
| P1 | 昊哥自己的 PRD、商业计划书 | `04-产品资产/`、`01-核心正本/` | 取舍、度量、推动 |
| P2 | 网站后台真实数据 | 昊哥提供或平台后台 | 度量 |
| P2 | Coze 产品真实使用记录 | 昊哥提供 | 度量、定义 |
| P2 | 竞品真实界面 | 直接打开用，不看测评 | 取舍、洞察 |
| P3 | 经典原始文本（梁宁课程原文案例、Amazon PR/FAQ、《The Mom Test》） | 已有蒸馏件 | 全部 |

## 二、禁止的材料

- 我的总结、我的框架、我的"洞察"
- 别人对方法论的二手解读
- 行业报告的结论（可作背景，不可作判断题）
- 我编的例子（哪怕很像真的）

**理由：被消化过的信息，练不出消化能力；编的例子，练出的是应付我。**

## 三、材料不足时的处理（重要）

1. 优先向昊哥要一句原话："把老板最近跟你说的一句话贴给我，什么都行。"
2. 其次从项目文件里取真实原文，注明文件与段落。
3. 两者都没有 → **停**，说"这轮缺一手材料，先不练"，不许编。

## 四、材料复用规则

- 同一段材料不连续用两次（他会记住答案，练的是记忆不是判断）
- 同一家店的材料间隔至少 3 轮
- 材料要用"片段"不用"整份"：只给判断必需的那几行，多给等于替他做完了信息筛选

## 五、材料的三个检验（出题前自问）

1. 这段材料里有没有"他没注意到的细节"？没有 → 题太浅
2. 这段材料的答案是不是唯一？唯一 → 考记忆，不是判断
3. 他能不能靠常识答对？能 → 换材料
