# 每轮协议细则（protocol）

> 何时读我：每次出题、追问、定位卡点前。

## 一、出题的四个硬要求

1. **材料必须是一手的**：原文、原始数据、真实对话。二手总结一律不用。
2. **材料必须可指认**：写清出自哪个文件、哪一段。
3. **只问一个问题**：出现第二个问号就是违规。
4. **不预告考点**：不说"这题考的是问题定义"。

## 二、追问话术库（按卡点层）

追问的唯一目的：让他自己看见依据里哪句是事实、哪句是假设。

### 通用三连（每轮只用一句）

- "你这句话里，哪部分是你亲眼看到的，哪部分是你推的？"
- "如果这个判断是错的，最先露出破绽的会是哪个现象？"
- "你刚才说'肯定'，依据是哪句话？"

### 看不见用户

- "他说的这句话，情绪是什么？不是意思，是情绪。"
- "他嘴上说要 A，如果 A 明天就给他，他会立刻掏钱吗？为什么不会？"
- "他上一次为类似的事掏钱，是为什么掏的？"

### 定义错问题

- "你说的'获客不够'，具体断在哪一步：不知道你、不信你、还是不着急？"
- "这个问题如果不解决，他下个月会损失什么？说得出数字吗？"
- "把'他需要 X'换成'他在什么情况下会主动找 X'，这句话怎么改？"

### 不会取舍

- "这一版去掉哪一项，剩下的还成立？"
- "如果预算只有现在的十分之一，你砍哪个？"
- "你保留这项，是因为它有用，还是因为你舍不得？"

### 不会度量

- "哪个数字变了，你会承认自己错了？"
- "这个数字现在是多少？不知道的话，你怎么知道变了？"
- "三个月后拿什么给老板看，他会说'值'？"

### 不敢决策

- "你在等什么信息？那个信息拿不到的话，你打算怎么办？"
- "最坏的结果是什么？发生了你赔得起吗？"

### 不会推动

- "这句话说完，他下一步会做什么动作？说不出动作就等于没说。"
- "现在这间屋子里，谁能让这事往前走一步？"

## 三、追问的三条禁令

1. 追问句里不许有判断（"你是不是没考虑成本"= 违规）
2. 一轮只问一件事
3. 三轮之内必须收，收不住就说明题出坏了，直接进 Step 5 并承认题目问题

## 四、卡点定位的写法（固定格式）

```
卡点：<六层之一>
证据：你说"<他的原话>"——这句话里 <哪部分是假设>。
```

不许写"整体感觉""可能有点"。必须引原话。

## 五、微训练的写法（固定格式）

```
微训练：<一个动作>
耗时：<5-30分钟>
产出：<一个可检验的东西：一句话/一张表/一个数字/一条消息>
检验：<怎么算做完了>
```

## 六、收尾的写法

```
下次练：<维度>｜因为：<radar 里最低分或连续未改善>
```

不写课程表，不写"接下来我们学…"。
